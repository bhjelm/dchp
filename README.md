# OpenID Foundation DCHP WG
The OpenID Foundation Digital Credentials Harmonized Presentation (DCHP) is a oint initiative by ISO/IEC JTC1/SC 17 (ISO) WG10 and WG4 and OpenID Foundation (OIDF) DCP WG to harmonize their respective credential exchange protocols for in-person and online credential presentation.
